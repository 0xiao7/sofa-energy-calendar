# 個人命盤能量曆（SoFa Engine 子專案）

八字（本命日主）× 農民曆（流日干支）→ 引動十神 → 當月每日「運勢能量」五級 → 點某天勾選實際感受 → 給實證取向的回穩建議。純前端、單檔、離線可跑。

## 三視角

### A. 給 Fay（流程 / 設計意圖）
- 輸入生辰 → 用日柱演算法推「日主」→ 當月月曆，每格一條五段電量棒（紅1→綠5）。
- 點某天：先看當日流日干支、引動十神、運勢能量等級與一句風險提示；再勾選實際有感的傾向 → 按「確認」才顯示各筆的具體建議與「你當日要注意的方面」。
- 定位提醒：八字→症狀的對應**無科學實證**，對外請定位為「自我覺察語言／產品敘事」；回穩之道本身採實證心理方法。

### B. 給 Ro（規格 / 不可動的點）
- **資料**：200 筆 = 8 類(C1–C8) × 25，且 10 個十神各 20 筆（平均分布）。欄位：`id, category, ten_god, name, common(常見表現), recovery(回穩之道), is_care`。
- **CSV 是真相來源**；改內容請改 CSV，再同步回 index.html 的 `SYM` 與（若用 DB）重新匯入。
- 高關懷 `is_care=true` 條目（深度封閉、自傷念頭、失去動力、完全耗竭、擺爛麻木、自毀式叛逆）：**只在能量 1–2 顯示**，且必須保留溫暖訊息＋台灣求助專線（1925/1995/1980）出口，不可暗示「等流日過去就好」。
- 假日紅字規則表 `HOLIDAYS`（2026 已填，含補假）；正式版建議改 fetch `ruyut/TaiwanCalendar` 或 data.gov.tw 自動更新。

### C. 給未來協作者 / Claude Code（技術脈絡）
核心演算法（皆在 index.html `<script>`）：
- **日柱干支**：`ganzhiIndex=(JDN+49)%60`，0=甲子。錨點已驗證：1900-01-01=甲戌、1949-10-01=甲子、2026-06-03=戊申。JDN%7==0=週一。
- **十神** `tenGod(日主,目標)`：五行 木0火1土2金3水4；同我=比肩/劫財、我生=食神/傷官、我剋=偏財/正財、剋我=七殺/正官、生我=偏印/正印；正(異陰陽)/偏(同陰陽)。
- **引動權重**：流日天干×3、地支本氣×2、餘氣×1。
- **能量分級**：`stress = Σ STRESS[十神]×引動權重`（七殺5/偏印4/傷官3/正官3/劫財3/偏財2/正財2/正印1/食神1/比肩1），再把**當月**所有日子相對切 5 級；電量 lv = 6−tier。
- **清單**：取主神被引動的症狀，依權重排序、取前 8，其餘進「顯示更多」。

### 已知限制 / 待辦（TODO）
1. **能量分級是「當月相對」**：跨月不可比，且高關懷出現與否會隨當月分布浮動。→ 可改「固定壓力門檻」版（建議優先）。
2. **個人化只到「日主級」**：同日主的人結果相同。→ 加「本命旺弱加權」（先用出生月份季節判得令）讓同日主也拉開差異。
3. **只算日柱**：年/月柱需節氣表才準（年柱看立春、月柱看節氣）。→ 接農民曆/節氣資料做完整四柱。
4. 日柱 23:00 後進位次日（早晚子時約定），未做可開關設定。

## 部署
純靜態。任一方式皆可：
- 本機：直接用瀏覽器開 `index.html`。
- GitHub Pages：將本資料夾推到 repo → Settings → Pages → 指向根目錄；`index.html` 會被當首頁。
- 任何靜態託管（Render static / Netlify / Vercel）皆可。
