# B.CLASS Wallet｜個人財務生存導航系統

> 人生不是只有餘額，而是現金流節奏。

這是一個**獨立專案**（與本 repo 的「個人命盤能量曆」無關），目標是做一個**人生現金流導航系統**：不只記帳，而是把收入、支出、負債到期日疊在同一張月曆上，用五色燈告訴你「未來哪一天會出事、現在還能撐幾天」。

## 怎麼跑（不需要模擬器、不需要後端）

這份 MVP 是**純前端單檔 HTML**，不依賴 Flutter、不需要 Android/iOS 模擬器、也不需要 Supabase：

- **最簡單**：直接用瀏覽器打開 `index.html`。
- **本機 server（避免某些瀏覽器限制）**：
  ```bash
  cd bclass-wallet
  python3 -m http.server 8000
  # 開 http://localhost:8000
  ```
- 資料存在瀏覽器 `localStorage`，重開仍在；右上角可「載入範例 / 清除資料」。

> 之後若要做正式 App（Flutter + Supabase），才會需要模擬器。原型階段刻意用 HTML，是為了**先驗證敘事有沒有打中人**，再決定投入 App 開發。

## MVP v0.1 已實作功能

對應規劃書「Milestone 1：看得到未來」：

- **月曆 Dashboard**：每格顯示淨收支 + 五色現金流燈（綠/黃/橘/紅/黑）。
- **逐日餘額推算**：期初餘額 + 預期收入 − 預期支出 − 當日到期 → 預估每日餘額。
- **生存導航卡**：可動用現金、可維持天數、預測斷裂日。
- **Daily Detail**：點任一天看當日收入/支出/結餘/現金流狀態 + 支出明細 + 規則型建議。
- **負債管理**：列出負債（剩餘、利率、到期日），一鍵切換**雪球法 / 雪崩法**還款順序。
- **固定收支（重複規則）**：薪資、房租、訂閱、貸款設定一次，自動長進未來月曆。
- **月報表**：總收入、總支出、淨現金流、支出分類比例。

> 危險度、生存天數、雪球/雪崩都是**純規則計算**（不需 LLM），正式版可原樣搬到後端。LLM 只建議用在 Pro 版的自然語言洞察。

## 顏色狀態定義

| 顏色 | 狀態 | 條件（當日預估餘額 vs 安全水位 buffer） |
| --- | --- | --- |
| 🟢 綠 | 安全 | 餘額 ≥ buffer |
| 🟡 黃 | 注意 | 50% buffer ≤ 餘額 < buffer |
| 🟠 橘 | 緊繃 | 25% buffer ≤ 餘額 < 50% buffer |
| 🔴 紅 | 危險 | 0 < 餘額 < 25% buffer |
| ⚫ 黑 | 斷裂 | 餘額 ≤ 0 |
